# 12 · Airfoil families

`Airfoil` builds NACA 4/5/6, CST, thickness-ratio families about the camber line,
flatback trailing edges, and Selig/Lednicer `.dat` files. Interpolation by t/c
blends two sections then rescales thickness.

```bash
python examples/12_airfoil_families/airfoil_families.py
```
